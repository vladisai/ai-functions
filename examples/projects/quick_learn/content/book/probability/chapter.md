# Symbols at a Glance

| **Symbol** | **Meaning** |
| --- | --- |
| $X, Y, S, A, R$ | random variables |
| $x, y, s, a, r$ | realizations |
| $\bm{x}, \bm{\mu}$ | vectors |
| $\bm{A}, \bm{\Sigma}$ | matrices |
| $\mathbb{P}(\cdot)$ | probability of an event |
| $p(\cdot), p_X(\cdot)$ | density / pmf |
| $\mathbb{E}[\cdot]$ | expectation |
| $\mathrm{Var}[\cdot]$ | variance |
| $\mathrm{Cov}[\cdot,\cdot]$ | covariance |
| $\mathrm{H}(\cdot)$ | entropy |
| $\mathrm{KL}(\cdot\|\cdot)$ | KL divergence |
| $I(\cdot;\cdot)$ | mutual information |
| $\bm{\theta}, \Theta$ | parameters, param. space |
| $\bm{F}(\bm{\theta})$ | Fisher information |
| $\pi(a\mid s)$ | policy |
| $V^\pi, Q^\pi$ | value functions |
| $\gamma$ | discount factor |
| $\mathcal{S}, \mathcal{A}$ | state / action space |
| $X \perp\perp Y$ | $X$, $Y$ independent |
| $X \perp\perp Y \mid Z$ | cond. independent |

# Prior

1. An object is equally likely to be anywhere in a region. We learn that it is in the left half. Which statement is right?
   - [ ] It is still equally likely to be anywhere in the whole region
   - [ ] The left half now has probability 1/2
   - [x] It is now equally likely to be anywhere in the left half, and the right half has probability 0

2. Evaluate these statements about base-2 logarithms:
   - [T] $\log_2 1 = 0$
   - [T] $\log_2 (v/2) = \log_2 v - 1$
   - [F] $\log_2 (v/2) = (\log_2 v)/2$

# Learned

1. We know the position of an object exactly. What is the entropy of its position?
   - [x] 0
   - [ ] 1 bit
   - [ ] It is infinite
   - [ ] It depends on the size of the map
2. The answer "it is on the left" rules out half of the possible positions. What happens to the entropy?
   - [ ] It is halved
   - [ ] It drops to zero
   - [ ] It stays the same, since the remaining region still has positive size
   - [x] It drops by one bit
3. Evaluate these statements:
   - [F] Each bit of information halves the entropy.
   - [T] Two answers that each rule out half of the remaining positions reduce the entropy by two bits.
   - [T] A position spread over a larger region of possible positions has a higher entropy.
